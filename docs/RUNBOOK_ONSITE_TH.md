# คู่มือหน้างาน KOKO Studio (สำหรับพนักงานหน้าตู้)

ใช้คู่มือนี้ตั้งตู้ก่อนงาน ดูแลระหว่างงาน และปิดงาน คำในเครื่องหมาย "..." คือชื่อปุ่มหรือเมนูในโปรแกรม

## 1. ก่อนวันงาน (ทำครั้งเดียวต่อเครื่อง)

1. ติดตั้งโปรแกรม KOKO Studio (ดาวน์โหลดจากหน้า "KOKO Studio ของฉัน" บนเว็บ)
2. เปิดโปรแกรม → "บัญชีและ License" → "เชื่อม License" นำรหัสที่ขึ้นไปยืนยันที่เว็บ (บัญชีของเจ้าของ → KOKO Studio → "เชื่อมเครื่องใหม่")
3. "ตั้งค่า" → "โฟลเดอร์เก็บภาพ" → "เลือกโฟลเดอร์" (แนะนำไดรฟ์ที่มีที่ว่างมากกว่า 20 GB)
4. "ตั้งค่า" → "ตั้งค่าขั้นสูง" ตั้ง "PIN ออกจากโหมดแขก" เพื่อไม่ให้แขกกดออกจากหน้าถ่ายภาพเอง
5. ถ้าใช้ QR ให้แขกโหลดรูปผ่านอินเทอร์เน็ตโดยไม่มีแพ็กเกจคลาวด์: ทำตาม `docs/GUEST_GALLERY_TUNNEL.md` (Cloudflare Tunnel) ครั้งเดียว

## 2. เลือกวิธีต่อกล้อง (เลือกอย่างใดอย่างหนึ่ง)

| วิธี | ใช้เมื่อ | ตั้งค่า | ความละเอียด |
|---|---|---|---|
| เว็บแคม / การ์ดจับภาพ HDMI / EOS Webcam Utility | อยากให้แขกเห็นภาพสดบนจอ | หน้า "ถ่ายภาพ" → ช่องกล้อง เลือกชื่อกล้อง | 720p–4K ตามอุปกรณ์ (EOS Webcam Utility ได้ 720p) |
| ดึงภาพจากกล้องผ่าน USB | กล้อง Canon / Nikon / Sony เสียบสาย USB แล้วกดชัตเตอร์ที่ตัวกล้อง | "ตั้งค่า" → "ดึงภาพจากกล้องผ่าน USB" → "เริ่มดึงภาพผ่าน USB" แล้วหน้า "ถ่ายภาพ" เลือก "ถ่ายที่ตัวกล้อง / มือถือ" | เต็มความละเอียดของกล้อง |
| โฟลเดอร์ | ใช้โปรแกรมถ่ายต่อสายตัวอื่น หรือกล้องส่งรูปเข้าโฟลเดอร์ | "ตั้งค่า" → "นำเข้าภาพจากกล้อง" → "เลือกโฟลเดอร์และเริ่ม" แล้วเลือก "ถ่ายที่ตัวกล้อง / มือถือ" | เต็มความละเอียด |
| มือถือเป็นกล้อง | ไม่มีกล้อง หรืออยากให้ช่างเดินถ่ายด้วยมือถือ | "ตั้งค่า" → "ใช้มือถือเป็นกล้อง" → สแกน QR ด้วยมือถือที่ต่อ Wi‑Fi เดียวกัน แล้วเลือก "ถ่ายที่ตัวกล้อง / มือถือ" | ตามกล้องมือถือ (ย่อเหลือด้านยาว 3,600 px) |

ข้อห้าม: **อย่าใช้โหมดเว็บแคมของ Canon (EOS Webcam Utility) พร้อมกับดึงภาพผ่าน USB** กล้องจะถูกจับไว้ในโหมดเว็บแคมและกดชัตเตอร์ไม่ได้ ถ้าเคยเปิดโหมดเว็บแคมไปแล้ว ให้ถอดสาย USB แล้วเสียบใหม่

## 3. ตั้งตู้ในวันงาน (ประมาณ 10 นาที)

1. ต่อไฟ กล้อง จอแขก และเครื่องพิมพ์ใบเสร็จ
2. เปิดโปรแกรม → "อีเวนต์" สร้างงาน (ชื่องาน วันที่) และเลือก "เทมเพลต"
3. หน้า "ถ่ายภาพ" เลือกกล้องตามข้อ 2 แล้วกดถ่ายทดลอง 1 รอบ
4. "ตั้งค่า" → "ตั้งค่าขั้นสูง" → "เครื่องพิมพ์ใบเสร็จ (QR ให้แขกสแกน)" → "ค้นหาเครื่องพิมพ์" → พิมพ์ใบทดสอบ
5. ถ้าใช้ QR ผ่านเครื่องนี้: "ตั้งค่า" → "แกลเลอรีของแขก" → "เปิดแกลเลอรีของแขก" แล้วกด "ตรวจว่าเปิดจากข้างนอกได้" ต้องขึ้น ✓
6. สแกน QR บนใบเสร็จรอบทดลองด้วยมือถือที่ **ปิด Wi‑Fi ใช้ 4G** ต้องเห็นรูปและกด "บันทึกทั้งหมด" ได้
7. "เปิดจอแขก" แล้ว "เริ่มโหมดแขก"

## 4. ระหว่างงาน

- ป้ายสถานะมุมบน: "เชื่อมต่อแล้ว" = พร้อม · "ไม่ได้รับภาพจากกล้อง" = ดูตารางแก้ปัญหาด้านล่าง
- แขกกดถ่าย → ตรวจรูป → "ยืนยันจบรอบ" → ใบเสร็จ QR ออกเอง (ถ้าเปิดพิมพ์อัตโนมัติ)
- ถ้าเน็ตหลุด ถ่ายต่อได้ตามปกติ รูปเก็บในเครื่องและขึ้นคลาวด์เองเมื่อเน็ตกลับ
- เจ้าภาพอยากได้ลิงก์รวมทั้งงาน: เว็บ → "KOKO Studio ของฉัน" → เลือกงาน → แท็บ "แชร์ลิงก์"
- ลบรูปที่ไม่เหมาะสม: เว็บ → เลือกงาน → แท็บ "รูป" → เลือกรูป → "ลบที่เลือก" (หรือในโปรแกรม "รอบถ่าย" → ลบทั้งรอบ)

## 5. แก้ปัญหาที่พบบ่อย

| อาการ | สาเหตุที่พบบ่อย | วิธีแก้ |
|---|---|---|
| ป้ายขึ้น "ไม่ได้รับภาพจากกล้อง" / ภาพดำมีรูปสาย USB กากบาท | กล้องหลุด หรือโปรแกรมอื่นจับกล้อง | ปิด digiCamControl / EOS Utility, ปิดเปิดกล้อง, ถอดเสียบ USB |
| กดชัตเตอร์ที่กล้องไม่ได้ขณะเสียบสาย | กล้องค้างในโหมดเว็บแคมของ Canon | ถอดสาย USB แล้วเสียบใหม่ อย่าเลือก EOS Webcam Utility ในช่องกล้องถ้าใช้โหมด USB |
| โหมด USB ขึ้น "พบกล้องแต่เข้าถึงรูปไม่ได้" | โปรแกรมอื่นใช้กล้องอยู่ | ปิดโปรแกรมของ Canon / digiCamControl แล้วถอดเสียบสาย |
| รอรูปจากกล้องนานจนขึ้นเตือน | ไม่ได้กดชัตเตอร์ หรือกล้องโฟกัสไม่ติด | ปรับเลนส์เป็น MF หรือหันหาที่มีแสง แล้วเริ่มรอบใหม่ |
| แขกสแกน QR แล้วเปิดไม่ได้ | เครื่องไม่มีเน็ต / Tunnel ไม่ทำงาน / แขกไม่ได้ต่อ Wi‑Fi งาน (กรณีไม่มี Tunnel) | เช็กเน็ต, กด "ตรวจว่าเปิดจากข้างนอกได้", รีสตาร์ทเครื่องเพื่อเปิด Tunnel |
| สแกนจากในแอป LINE แล้วบันทึกไม่ได้ | เบราว์เซอร์ในแอป LINE | กด ••• → "เปิดในเบราว์เซอร์" แล้วบันทึกใหม่ |
| ใบเสร็จไม่ออก | เครื่องพิมพ์ออฟไลน์ / กระดาษหมด | ดูสถานะใน "ตั้งค่าขั้นสูง" → เครื่องพิมพ์ใบเสร็จ ("เครื่องพิมพ์ออฟไลน์ ตรวจสายและไฟ"), พิมพ์ซ้ำจาก "รอบถ่าย" |
| พื้นที่เก็บใกล้เต็ม | รูปเยอะ | ย้ายรูปงานเก่าไปเก็บที่อื่น หรือเลือกโฟลเดอร์ไดรฟ์ใหม่ก่อนงานถัดไป |

## 6. ปิดงาน

1. กด "กลับไปหน้าควบคุม" มุมบนขวาของหน้าแขก แล้วใส่ PIN
2. รอให้สถานะอัปโหลดครบทุกรอบ (ถ้าใช้คลาวด์)
3. สำรองข้อมูลลงฮาร์ดดิสก์ภายนอก (PowerShell):
   ```
   powershell -ExecutionPolicy Bypass -File scripts\backup-booth-data.ps1 -Destination E:\KOKO-backup
   ```
   สคริปต์คัดลอกรูปและข้อมูลงาน ไม่ลบอะไรจากเครื่อง และไม่คัดลอกไฟล์ License
4. ปิดโปรแกรม ปิดกล้อง ปิดเครื่องพิมพ์
